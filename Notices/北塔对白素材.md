# 北塔对白素材

本版在牢房、地下禁闭区、档案室与终审厅门前设有角色对白。靠近地面提示按 F 开始，按 F 读下一句，Esc 跳过当前场景。读完或跳过后记录到存档。

对话框上方显示当前说话人的半身。界面上的「北塔模型」表示游戏正在实时渲染二创工程里的角色模型。新对白以中文字幕演出。接入原版立绘或录音需有相应的使用许可，范围见官方指南第 7、9 条。 [Acacia 二创指南](https://manosaba.com/guidelines)

## 加载有使用权的本地素材

先启动一次游戏。在 `ManosabaDuel/NorthTower200User/Saved/` 下创建 `NorthDialogue` 文件夹。用自定义存档目录启动时，使用其 `Saved/NorthDialogue` 文件夹。

- 半身立绘放在 `Portraits/Ema/`、`Portraits/Hiro/` 或 `Portraits/Yuki/`。文件使用透明 PNG，宽高各不超过 2048 像素。可使用 `Smile.png`（微笑）、`Neutral.png`（平静）、`Concern.png`（担忧）、`Resolve.png`（坚定）、`Soft.png`（柔和）和 `Startled.png`（惊讶）。3.4.6 的艾玛、希罗日常对白和短提示默认读取 `Smile.png`；缺少指定情绪时，优先回到同角色已核对的微笑图。小雪保留自身情绪和常态默认。
- 逐句录音放在 `Voice/PrisonLetters/主人公/场景/行号_说话人.wav`。角色文件夹和文件名使用 `Ema`、`Hiro`、`Yuki`。录音用单声道 16 位 PCM WAV，采样率 8–48 kHz，长度 0.1–20 秒。例如，艾玛路线在牢房初次听见希罗时，首句文件应为 `Voice/PrisonLetters/Ema/CellEcho/01_Hiro.wav`。希罗路线里，艾玛在同处的首句文件为 `Voice/PrisonLetters/Hiro/CellEcho/01_Ema.wav`。播放时使用暂停菜单里「语音」的音量设置。

场景文件夹名称按下表填写。行号与游戏对话框中的数字一致。每行录音应与该路线中的说话人和字幕对应。游戏会在打开该句时读取本地文件。

另可在艾玛和希罗各自的立绘目录放置 Witch.png。进入她们的北塔战斗并首次魔女化时，画面边缘短暂显示这张半身立绘。日常对白依照台词选择常态或对应表情。
3.4.1 支持同一 Windows 用户共享立绘。将相应的 Ema、Hiro、Yuki 文件夹放入 %LOCALAPPDATA%/ManosabaDuel/NorthDialogue/Portraits 即可。每个存档也可使用 Saved/NorthDialogue/Portraits 内的同名文件。
3.4.2 中，Hiro/Neutral.png 用于微笑的日常立绘，Hiro/Urgent.png 与 Hiro/Angry.png 分别用于着急与生气。调查对白沿用各自角色和情绪的文件。

3.4.6 把艾玛 `Ema_08`、希罗 `Hiro_01` 两张原版微笑半身图按原字节保存在 `Content/DuelPortraits/<角色>/Smile.png`，用于没有个人立绘文件时的默认显示。它们沿用此前原图裁切记录，未重画嘴部或合成表情；文件 SHA-256、第三方原画索引页和来源分类见同目录 `PORTRAIT_SOURCES346.json`。公开收录不等于另行取得再发行许可，原画权利仍属原权利人。旧档中的对话完成记录保持不变；旧 `Neutral.png` 中错放的惊恐表情不会覆盖新的微笑默认。真正的惊恐仅留在主角眼前再次出现幻象的句子，正在异变的少数句子使用担忧图。

实际运行验证保留在 `Verification/TravelFinalDX12` 和 `Verification/SmileHUD346`：微笑专项在有图形的正式 DX12 启动中通过，两个主角视角分别读取到原版艾玛与希罗的2D微笑纹理，1600×900对白截图及同名凭证记录了实际说话人、台词、纹理尺寸和表情。两条完整路线的普通台词分别为艾玛路线77/82、希罗路线72/78采用微笑，各仅1句明确的即时幻象惊讶。
